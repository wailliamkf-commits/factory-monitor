## MUST-FIX findings

1. **P1 — Lossy preview publication can delete durable control messages.** `src/factory_monitor/runtime.py:27-40,78-85`: `_put_bounded(messages, full_frame)` uses the same queue as observations, analysis and evidence completion. On saturation it removes the oldest arbitrary message. A dropped evidence completion leaves the persisted event recording indefinitely; a dropped analysis never reaches SQLite. Safe reproduction: a size-one queue containing `evidence_update` followed by `_put_bounded(...full_frame)` contains only `full_frame`. Separate lossy frame traffic from reliable lifecycle/control traffic and test saturation with terminal updates.

2. **P1 — Live evidence is attributed using unconditional grid crops.** `src/factory_monitor/runtime.py:213-214`: evidence worker crops every camera from every captured frame without camera identity or layout verification. Enlarging CAM01 produces ten clips labelled as different cameras from portions of CAM01. Detection separately assumes a grid (`:138-139`), so selected detail is also unavailable for meaningful camera-relative rule inference. Every consumer must use verified capture-time mapping, recording explicit gaps for unverified/nonvisible cameras; detail evidence must map only to the verified selected camera. Owner was implementing this repair during review.

3. **P1 — Evidence silently omits requested pre-roll and corrupt frames.** `src/factory_monitor/evidence.py:105-109,169-175`: start never records the gap from requested pre-window start to first available cached frame; finalization silently skips undecodable nonfirst JPEGs. Safe reproduction A: first cached frame at100, event100, continuous5fps through160 returns `recording_status=complete`, `gaps=[]`, clip60.2s despite requested pre30/post60. Reproduction B: continuous99..101 at5fps, corrupt the second of11 JPEGs before finalization; result `complete`, `gaps=[]`,10 encodedframes. Track requested coverage and decode omissions explicitly, and do not advertise unqualified complete coverage. Related playback issue: frames70 and160 produce0.4s clip with gap70..160 in the manifest; playback collapses time unless timestamps/gaps are shown. Add missing-pre, corruption and time-axis tests.

4. **P1 — The15s queue-inclusive review deadline is not independently enforced.** `src/factory_monitor/runtime.py:225-252,490-497`; `src/factory_monitor/inference.py:181-192`: tasks become timeout only after the single reviewer dequeues/completes them. There is no controller watchdog for pending tasks or dead review worker. HTTPX's operation/read-inactivity timeout does not enforce a total deadline while response chunks keep arriving; the post-response deadline check only notices after the request ends. A stuck/dead reviewer leaves pending records beyond15s and blocks later tasks. Add a controller-owned deadline registry, terminal timeout updates and rejection of late results; isolate/restart hung work without delaying candidate persistence/evidence.

5. **P1 — Manual view requests bypass the global switching policy and concurrency gate.** `src/factory_monitor/runtime.py:368-388`: GUI requests call the native controller directly, never enqueue/confirm policy transitions or set `_view_action_running`. Manual detail can remain indefinitely with policy still reporting grid; manual and automatic clicks can overlap. Route manual and automatic actions through one serialized state machine with coverage accounting, verified return and bounded dwell. Test a manual request during automatic switching and a manual detail with no follow-up action.

6. **P1 — Native click safety verifies the view only after sending global input.** `src/factory_monitor/capture/control.py:121-130,151-160,180-187`: preflight compares saved dimensions/calibration values; static window origin feeds OS-global clicks. Window movement, focus loss, DPI scaling or an overlay can direct the click into an unrelated app before post-click verification fails. Prevalidate current target/window bounds, coordinate scale and focus/occlusion, or keep native automation disabled without an adapter able to prove safe target dispatch. Test focus, movement, scaling and popup faults before clicking.

7. **P1 — Readback arrival is mistaken for capture freshness.** `src/factory_monitor/runtime.py:440-445,545-551`: packet timestamps are discarded when caching full frames; `_wait_for_fresh_frame` accepts any newly handled queue message. A frame captured before the click but delivered later can satisfy the fresh-frame test and confirm stale grid/detail identity. Carry capture timestamp/sequence across the action boundary and require capture after the actual action; test delayed pre-click packets.
